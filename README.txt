TXT-ED Chromebook版（PDF処理ライブラリ同梱・完全オフライン構成）

内容:
- index.html : TXT-ED本体
- sw.js : 同一オリジンのオフラインキャッシュ
- manifest.json : PWAインストール設定
- icon-192.png / icon-512.png : アプリアイコン
- libs/pdf.min.js : PDF.js 3.11.174（PDF読み込み・表示）
- libs/pdf.worker.min.js : PDF.js 3.11.174 worker
- libs/pdf-lib.min.js : pdf-lib 1.17.1（PDF書き出し）

オフラインについて:
- PDF処理ライブラリを含む必要ファイルはすべてこのZIPに同梱しています。
- HTMLおよびService Workerから外部CDNへのライブラリ参照を取り除いています。
- アプリ起動後にインターネットからライブラリを取得する必要はありません。
- PWAとしてオフライン利用する場合は、HTTPSまたはlocalhostで配信してService Workerを登録してください。同じ配信元から初回起動してキャッシュを作成した後、オフラインで起動できます。
- file:// でHTMLを直接開く場合、Service Worker/PWAは利用できません。ローカルファイル起動での動作は保証しません。

基本操作:
1. ZIPを展開し、ファイルとlibsフォルダを同じ構成のまま保持してください。
2. HTTPSまたはlocalhostでindex.htmlを配信し、Chromeで開きます。
3. インストール可能な場合はChromeのインストール操作から追加します。
4. PDF閲覧欄の「フォルダ選択」でPDFが入ったフォルダを選び、一覧からPDFを選択します。
5. PDFは画面全体ではなく、中央のエディタ領域に表示されます。上部の文字入力・編集ツールと右側のテキスト/PDF一覧は表示されたままです。

PDFへの書き込み・書き出し:
- PDFを開くと、PDF.jsで各ページをアプリ内に描画して表示します。
- 「文字書込」を選ぶと、各ページの上に文字を入力できます。
- 「手書き」を選ぶと、各ページの上にペンで線や文字を書けます。
- 「PDF操作」に戻すと、ページのスクロールができます。
- 書き込みを行うと、アプリ上部の編集メニューに「書き出し」ボタンが表示されます。
- 「書き出し」を押すと、元PDFの各ページに書き込みを合成したPDFを保存し、同時にページごとのPNG画像も保存します。
- 書き出しは元PDFのページを画像化して上に重ねる方式です。書き込みは見た目として固定され、元PDFの文字・図形を個別に編集することはできません。
- 複数ページのPNG出力では、Chromeが複数ファイルのダウンロード許可を求める場合があります。

注意:
- フォルダアクセスAPIの利用可否や権限はChromeOS/Chromeのバージョンに依存します。
- 実機のChromebookでの最終動作確認はこの環境では実施できていません。
